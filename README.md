
# Data and code to analyze the lagged effects of moisture availability on wildfire burn severity in the boreal forest

This Repository contains data and code for the article:

Goldman JA, Fortin MJ, James PMA. 2026. Within and among years atmospheric moisture availability influencs burn severity in the boreal shield. Fire Ecology [10.1186/s42408-026-00544-x](https://doi.org/10.1186/s42408-026-00544-x)

`The authors request that you cite the above article and the data when using these data or modified code to prepare a publication.`
